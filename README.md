# Agent CLI

A command-line interface agent built with LangChain.

## Installation

```bash
pip install -e ".[dev]"
```

## Usage

### Run a single prompt

```bash
agent run --prompt "Your prompt here"
```

### Start interactive chat

```bash
agent chat
```

## Configuration

Copy `.env.example` to `.env` and fill in your API keys:

```bash
cp .env.example .env
```
